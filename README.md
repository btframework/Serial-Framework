# Serial Framework

This repository contains sample applications for the [Serial Framework](https://www.btframework.com/serialframework.htm).

## Build configuration
### .NET WinForms

.NET Framework 4.0, Visual Studio 2022

### .NET macOS

.NET 9.0 Core, Visual Studio Code (no MAUI or Xamarin required)

### VCL (Windows)

RAD Studio (Delphi/CBuilder) 10

### Lazarus (Windows and macOS)

Lazarus 4.2 with FreePascal 3.2.2
