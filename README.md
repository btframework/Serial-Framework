# Serial Framework

This repository contains sample applications for the [Serial Framework](https://www.btframework.com/serialframework.htm).  

The **Serial Framework** is a **Software Development Kit** (SDK) for serial port communication (**COM**, **UART**, **RS232**) on **Windows** and **macOS**. It simplifies interaction with modems, barcode scanners, IoT devices, and other serial equipment, and can be used standalone or as part of the Wireless Communication Library.  

## Key features
- COM port and modem enumeration  
- USB device enumeration, monitoring, and state reading  
- Serial data exchange, serial port events, and signal controls  
- Modem event handling  
- Hardware changes and system power states monitoring  
- Support for Com0Com, Bluetooth virtual COM, USB virtual COM, and UART  
- OBEX client and server with Object Push Profile (OPP) and File Transfer Profile (FTP)  
- Windows and macOS compatible
