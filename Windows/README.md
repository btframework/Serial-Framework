# Serial Framework Examples – Windows

This directory contains the [Serial Framework](https://www.btframework.com/serialframework.htm) example applications for Windows.  

The **Serial Framework** is an SDK for serial port communication (COM, UART, RS232) on **Windows** and **macOS**.  

## Directory structure
| Folder | Description |  
| ------ | ----------- |  
| Apps | Sample applications for Windows |  
| Libs | Required Serial Framework libraries for the samples |  

### Apps

The **Apps** folder contains all sample applications that demonstrate how to use the Serial Framework on Windows.  

### Libs

The **Libs** folder contains the Serial Framework libraries required to build and run the sample applications.  

## Build configuration
Windows samples can be built with the following configurations:  
| Platform | Toolchain |  
| -------- | --------- |  
| .NET WinForms | .NET Framework 4.0, Visual Studio 2022 |
| VCL | RAD Studio (Delphi/C++Builder) 10 |
| Lazarus | Lazarus 4.2 with FreePascal 3.2.2 |
