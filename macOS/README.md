# Serial Framework Examples – macOS

This directory contains the [Serial Framework](https://www.btframework.com/serialframework.htm) example applications for **macOS**.  

The **Serial Framework** is an SDK for serial port communication (COM, UART, RS232) on **Windows** and **macOS**.  

## Directory structure
| Folder | Description |  
| ------ | ----------- |  
| Apps | Sample applications for macOS |  
| Libs | Required Serial Framework libraries for the samples |  

### Apps
The **Apps** folder contains all sample applications that demonstrate how to use the Serial Framework on macOS.  

### Libs
The **Libs** folder contains the Serial Framework libraries required to build and run the sample applications.  

## Build configuration
macOS samples can be built with the following configurations:  
| Platform | Toolchain |  
| -------- | --------- |  
| .NET macOS | .NET 9.0 Core, Visual Studio Code (no MAUI or Xamarin required) |
| Lazarus (macOS) | Lazarus 4.2 with FreePascal 3.2.2 |
